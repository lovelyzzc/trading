# 术语表（Glossary）

- ADX（Average Directional Index）：衡量趋势强度，不分方向。
- DMI（Directional Movement Index）：含 `+DI` 与 `-DI`，分别衡量上升/下降动能。
- ML Adaptive SuperTrend：基于波动率聚类（如 K-Means）的自适应 SuperTrend，用于趋势方向与动态支撑/阻力。
- 共振（Resonance）：强度/方向/动能三要素同时对齐的状态。
- 强单边上涨趋势（Strong Uptrend）：`ADX>阈值` 且 `SuperTrend 看涨翻转` 且 `+DI 显著强于 -DI`。
- 回调买入（Buy the Dip）：趋势内回落至关键支撑并企稳后的买入。
- 突破买入（Breakout）：突破重要盘整或前高后的买入。
- 交易成本：单笔预先定义并可承受的亏损。
- 过程波动：系统在非趋势环境中的正常回撤。
- 毁灭性打击：导致无法继续交易的重大资本损失，必须杜绝。
